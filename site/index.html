Kernel research · pre-registered · replayable

Price the ceiling before you write the kernel.

Most kernel write-ups never state a ceiling, so any gain looks like progress. This project makes the ceiling an input: compulsory bytes, a measured floor, a predicted upper bound. Five archived cases replay offline — four of them say no.

01

The gate

Bytes

Sum the compulsory traffic: weights, activations, output. It cannot be argued down. A mechanism can only remove what it touches.

Floor

max(bytes / BW_eff, flops / FLOP_eff), both measured. A same-bytes reference kernel can raise the floor and can never lower it.

max( B / 1.613 TB/s , F / 138 TFLOPS )

Verdict

GO only if the conservative end of the band clears 1.30×. Below 1.15× is NO-GO. In between is INCONCLUSIVE — an honest answer, not a failure.
